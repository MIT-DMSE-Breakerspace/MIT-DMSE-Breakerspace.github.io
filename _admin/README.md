# Breakerspace Administrative Records

This underscore-prefixed directory contains internal administrative runbooks, system audits, editing guides, and completion records. Jekyll must not publish it as part of the website.

The repository may still be publicly readable. Do not store credentials, API secrets, private student information, response exports, access codes, or other confidential information here.

## Folder Boundary

Use this directory for maintaining external administrative systems such as LibCal and Qualtrics. These records support the lab manager or a specifically delegated Breakerspace Lab Assistant; they are not trainer delivery materials.

Use [`../_staff-training/`](../_staff-training/) for the materials a trainer needs to prepare for and deliver a consistent instrument training. Use [`../_staff/`](../_staff/) for cross-site planning and internal operating procedures that are not tied to one administrative platform.

## Current Records

* `libcal-event-templates.md` preserves the pre-revision LibCal template audit and the verified 2026-08-04 outcome.
* `libcal-manual-update-guide.md` records the field-by-field LibCal update procedure and completion evidence.
* `qualtrics-launch-review.md` records the completed production and accessibility closeout.
* `qualtrics-manual-edit-guide.md` is the page-by-page Qualtrics copy deck and editing checklist.
* `qualtrics-survey-audit.md` preserves the source survey map, rationale, and revision plan.

Keep live credentials and person-specific records in the approved administrative system, not in this repository.
